# TETORD 3.4.0 — Git upload

This folder is prepared to be used as the repository root.

## Upload

1. Extract this ZIP.
2. Open the extracted folder in GitHub Desktop or Git.
3. Commit the files with a message such as:
   `Release TETORD 3.4.0 — Files PRO`
4. Push to the `main` branch.

## Important

- `node_modules/` and `dist/` are ignored by `.gitignore`.
- `package.json` is synchronized to version `3.4.0`.
- `VERSION` is `3.4.0`.
- The `.github/workflows/build-windows.yml` workflow is included.
